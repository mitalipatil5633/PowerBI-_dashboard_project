# PowerBI-_dashboard_project
•	Designed and built an interactive Sales Performance Dashboard in Microsoft Power BI to visualize over 11 million units of sales data and track product revenue across multiple manufacturers.
•	Created bar charts, pie charts, and map visuals to analyze regional sales and revenue share across 14 distinct manufacturers.
•	Consolidated key performance indicators (KPIs) — total revenue, unit volume, and product count — into a single executive-level dashboard for streamlined reporting
